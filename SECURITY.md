# Security policy

## Reporting a vulnerability

Please do **not** open a public issue, pull request or discussion about a
security problem.

Report it privately instead: on this repository's page open the **Security**
tab and choose **Report a vulnerability**. Only the owner sees the report.

Please include:
- what the problem is and where (page, route or file);
- the steps to reproduce it;
- what an attacker could do with it.

You will get an answer as soon as possible. Please give a reasonable time to fix
the problem before telling anyone else about it.

## Scope

- In scope: the code in this repository.
- Out of scope: denial-of-service and load testing, social engineering, and
  automated scanning of a live shop.

Never access, change or delete other people's data while testing. Use a local
copy of the shop instead: see "Running locally" in the README.
